# Test 001 — Takeoff, Hover and Return-to-Home

## Test Summary

| Item | Result |
|---|---|
| Test ID | TEST-001 |
| Date | 22 August 2026 |
| Environment | PX4 Software-in-the-Loop (SITL) |
| Vehicle | Gazebo x500 Quadcopter |
| Ground Station | QGroundControl Daily |
| Test Result | **PASS** |

## Objective

The objective of this test was to verify that the simulated x500 quadcopter could:

- Connect to QGroundControl
- Acquire a simulated GPS position
- Arm successfully
- Take off vertically
- Maintain a stable hover
- Execute Return-to-Home
- Land and disarm automatically

## Test Configuration

- Operating system: Windows 11
- Linux environment: Ubuntu 22.04 on WSL2
- Autopilot: PX4 SITL
- Simulator: Gazebo Harmonic
- Vehicle model: x500 quadcopter
- Ground-control station: QGroundControl Daily
- Communication protocol: MAVLink over UDP
- WSL communication port: 18570
- Rendering mode: Software rendering
- Build mode: Single compilation job (`-j1`)

## Test Procedure

1. Started PX4 SITL with the Gazebo x500 model.
2. Connected QGroundControl to PX4 through a manual UDP link.
3. Confirmed that QGroundControl displayed the vehicle as Ready.
4. Verified GPS availability and satellite count.
5. Set the commanded takeoff height to 3 metres.
6. Commanded the vehicle to take off.
7. Observed the quadcopter hovering in Gazebo.
8. Activated Return-to-Home.
9. Observed the vehicle returning to the home position.
10. Confirmed automatic landing and disarming.

A PX4 `.ulg` flight-log file was also generated by the simulation.

## Problems Encountered and Solutions

### 1. Build stopped because of insufficient RAM

The first parallel build was terminated with:

`fatal error: Killed signal terminated program cc1plus`

The build was restarted successfully using a single compilation job:

`make -j1 px4_sitl gz_x500`

### 2. Gazebo displayed a grey screen

The simulation was running, but the x500 model was not rendered correctly. Gazebo was restarted using software rendering:

`LIBGL_ALWAYS_SOFTWARE=1 make -j1 px4_sitl gz_x500`

The vehicle then appeared correctly.

### 3. QGroundControl did not connect automatically

A manual UDP communication link was created using the WSL IP address and port 18570. QGroundControl then connected successfully and displayed live vehicle telemetry.

## Conclusion

The first PX4 SITL flight test passed successfully. The simulated x500 quadcopter completed takeoff, stable hover, Return-to-Home, automatic landing and disarming. This confirms that the initial PX4, Gazebo, GPS, MAVLink and QGroundControl simulation environment is operational.
